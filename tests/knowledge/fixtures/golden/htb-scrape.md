Reconnaissance Decisions
========================

Build an inventory from independent observations before choosing an intrusive test. Record scope, collection time, confidence, and contradictions. An identifier copied from a single source remains a hypothesis until another observation supports it.

Choose a discriminating action
------------------------------

Prefer the action that separates the leading explanations while changing the target as little as possible. Write down the expected result for each explanation before acting, then compare the actual response with those predictions.

```text
observation -> hypothesis -> discriminating test -> evidence
```

Interpret the response
----------------------

Treat a timeout, denial, or empty response as evidence about the path taken, not as proof that the original idea was impossible. Recheck prerequisites and vantage point before discarding the hypothesis.
