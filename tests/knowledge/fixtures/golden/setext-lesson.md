Reason from observations
========================

Record what the target actually returned before choosing an explanation. Keep observed facts separate from assumptions copied from similar cases.

Choose the next test
--------------------

Select a low-impact action that distinguishes the leading hypotheses and state the expected outcomes before running it.

```text
request -> response -> revised confidence
```

Review the result
=================

If the response contradicts the preferred explanation, revise the weakest prerequisite instead of repeating the same action.
